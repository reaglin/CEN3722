CEN3722 — Introduction to Human Computer Interfaces

Cognitive Walkthrough Evaluation Method

This module explores the Cognitive Walkthrough, a structured usability inspection technique in which evaluators systematically step through an interface's task sequences to identify potential breakdowns in learnability. Topics include its theoretical foundations, preparation requirements, four guiding evaluation questions, and its practical application in interface design and assessment.
