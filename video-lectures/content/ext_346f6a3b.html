Summary: This video lecture covers the topic of Displays as part of the CEN3722 Human-Computer Interaction course at Daytona State College. It addresses standard concepts and principles related to how information is visually presented to users through display systems. The lecture is part of a broader series spanning key HCI topics including human factors, ergonomics, and interface design.

Relevance to Module: Displays are a foundational topic in Human-Computer Interaction, directly connecting to how interface design decisions affect user perception, cognition, and task performance. Understanding display principles informs how designers present information in ways that align with human perceptual and cognitive capabilities. This video fits within the broader module coverage of human factors, ergonomics, and advanced interfaces.

Pedagogical Purpose

This lecture provides an alternate, structured explanation of display design principles, reinforcing students' understanding of how interface elements must be designed to match human perceptual and cognitive constraints — directly supporting MO1 by grounding display considerations in memory and perceptual capacity limits. It also supports MO2 by illustrating how poor display design can create mismatches between what users expect and what a system presents, contributing to systematic errors. Instructors would include this resource to give students a focused, course-aligned treatment of displays as a critical component of interface design decision-making.
