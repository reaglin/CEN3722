CEN3722 User Testing

Author / Site: Daytona State College - Instructional Resources

Summary: This video lecture covers the topic of user testing as part of a Human-Computer Interaction course (CEN3722). It addresses foundational concepts and methods related to conducting user testing as a form of usability evaluation. The content is designed to support students in understanding how real users are involved in assessing the effectiveness and usability of interactive systems.

Relevance to Module: User testing is a core topic within the module's coverage of Usability Evaluation and User Testing, making this video directly aligned with the module's focus on evaluating interactive systems. It complements related lectures on usability evaluation techniques and human factors by offering a dedicated exploration of user-centered testing approaches.

Pedagogical Purpose

This video lecture provides students with an instructor-led explanation of user testing methods, offering an alternate or supplementary explanation to course readings and supporting students in achieving MO4, which requires them to evaluate and select appropriate usability evaluation techniques by comparing expert-driven methods with user testing approaches. By explicitly addressing user testing as a distinct methodology, the resource helps students understand when and why user testing is the appropriate choice over structured expert-driven alternatives such as heuristic evaluation.
