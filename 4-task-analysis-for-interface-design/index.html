Module 4

Task Analysis for Interface Design

Introduces hierarchical and cognitive task analysis methods used to decompose user goals into discrete, observable steps that inform interface structure. Students apply these methods to produce full task analysis documentation for their group project.

    Foundations of Task Analysis

    A reading that introduces task analysis as a core UX and interface design practice, explaining what it is, why it matters, and how breaking down human activity into constituent parts helps designers build systems that support real-world user behavior.

    Topic Detail🌐 Web page
    Hierarchical Task Analysis (HTA)

    A reading covering Hierarchical Task Analysis (HTA), tracing its origins in industrial and military psychology and explaining how the method decomposes complex user goals into progressively smaller sub-tasks, which learners use to understand and document observable task structures.

  • 📄
    Topic Detail🌐 Web page
    Cognitive Task Analysis (CTA)

    A reading on Cognitive Task Analysis (CTA) that addresses the mental processes underlying user actions — such as expert decision-making and knowledge application — filling the gap that HTA leaves by going beyond observable steps to capture what users think and know during task execution.

  • 📄
    Topic Detail🌐 Web page
    Comparing and Selecting Analysis Methods

    A reading that compares HTA and CTA as complementary rather than competing methods, guiding learners and instructors in selecting the appropriate analysis technique based on project context, task complexity, and the type of information needed.

    Topic Detail🌐 Web page
    Data Collection for Task Analysis

    A reading on empirical data-collection techniques used to feed task analysis, covering methods such as observation and interviews, and explaining how to gather reliable, real-world evidence about how users actually perform tasks before analysis begins.

    A reading explaining how to translate raw observational and interview data into structured, team-readable task analysis documents, covering documentation formats, verification practices, and how to produce artefacts that are ready to inform design decisions.
