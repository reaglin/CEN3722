CEN3722 — Introduction to Human Computer Interfaces

Module 4 — Task Analysis for Interface Design

This module introduces the principles and practice of task analysis as a foundational technique in human-computer interface design. Topics include Hierarchical Task Analysis (HTA), Cognitive Task Analysis (CTA), and frameworks for selecting the right method for a given design context.
