CEN3722 — Introduction to Human Computer Interfaces

Interface Prototyping with Figma

This module introduces learners to interface prototyping using Figma. Topics span core Figma concepts — including frames, grids, component libraries, and auto-layout — through to building interactive low- and high-fidelity prototypes.
