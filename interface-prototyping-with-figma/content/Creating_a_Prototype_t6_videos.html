Introduction

High-fidelity design is the stage where a grey-box wireframe becomes something that looks and feels like a real product. The structural work is already done — boxes, spacing, and flow — and now you decide what the interface actually looks like: colour palettes, type scales, photography and fills, icons, and subtle effects such as shadows, blurs, and overlays that communicate elevation and focus.

This matters in CEN3722 because visual properties are not decoration; they carry meaning. Type size and weight tell users what to read first, colour signals state and status, consistent icons make actions recognisable, and a shadow suggests that something is clickable or floating above the page. Figma supports this through styles (and variables) — reusable definitions for colour, text, and effects — so that a change made once propagates everywhere, which is the practical foundation of a design system.

The three videos below focus on the styles side of high-fidelity work, with the deepest coverage on typography and text hierarchy. While watching, pay attention to how each presenter decides what to turn into a reusable style versus what stays a one-off local setting, how styles are named and organised, and how font size, weight, and spacing are used to build a readable hierarchy. Treat the techniques as transferable: the same create-once-reuse-everywhere logic applies to colour styles, effect styles, and the image fills and icon assets you add to your own project.
