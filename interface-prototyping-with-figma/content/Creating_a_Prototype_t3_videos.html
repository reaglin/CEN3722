Introduction

A component library is a collection of reusable interface elements — buttons, input fields, cards, navigation bars, icons — that you define once and then reuse throughout a prototype. In Figma, you create a main component and then place instances of it wherever it is needed; editing the main component updates every instance at once. This is the practical mechanism behind the design principle of consistency: instead of manually keeping twelve buttons looking alike, you maintain one definition and let the tool propagate changes.

For this course, components matter because your interface project will likely involve many screens that share the same controls. Building a small library early saves time, reduces visual inconsistencies that confuse users, and makes late-stage changes feasible rather than painful. Variants extend this idea by grouping related states of the same element — default, hover, pressed, disabled — under one component, so you can swap states from a tidy set of properties rather than hunting through a sprawling layer list.

As you watch the three videos below, pay attention to four things: how an existing selection is converted into a main component and what visually distinguishes a main from an instance; how variants are organized and named so the property controls read sensibly; how component properties let you expose text, booleans, and nested instances for swapping; and where components live once created — the Assets panel and, for shared work, a published team library. Try each step in your own file as you watch; components are easier to understand by building than by reading about.

About this video

This video introduces component properties and walks through creating them. Properties are the mechanism for exposing configurable parts of a component — such as text content, the visibility of an element, or which nested instance appears in a slot — directly in the right-hand panel. It should clarify how a single flexible component can replace many near-duplicate ones.

Why this video
