Introduction

Auto-layout is Figma's system for building frames that arrange their children automatically along a horizontal or vertical axis. Instead of nudging rectangles and text into position by hand, you declare how a frame should behave: how much space sits between items, how much padding surrounds them, how children align, and whether the frame hugs its contents, fills available space, or stays a fixed size. The result is a button that grows when its label gets longer, a card that stretches to fit a longer description, and a list that reflows when you add or remove a row.

This matters in CEN3722 because your prototype should survive contact with real content. Interfaces that only look right with placeholder text tend to break when a user name, product title, or error message is longer than you planned. Auto-layout also pairs naturally with components: a well-built auto-layout component can be reused across screens, swapped, and resized without redrawing anything, which keeps your interface consistent and your file manageable.

As you watch, pay attention to four things: where auto-layout is applied (parent frame versus nested child frames), which sizing mode each element uses and why, how spacing and padding values are set, and how the presenter tests the layout by changing content or dragging the frame's edges. Try to rebuild each example yourself rather than only watching — auto-layout is much easier to understand through your own clicks than through description. Note also that Figma's auto-layout has gained features over time, so menu names and panel positions in older videos may differ slightly from the current interface.
