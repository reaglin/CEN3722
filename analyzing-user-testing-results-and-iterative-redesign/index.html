CEN3722 — Introduction to Human Computer Interfaces

Analyzing User Testing Results and Iterative Redesign

This module guides learners through the full lifecycle of usability analysis and design improvement: from interpreting quantitative and qualitative test data and diagnosing error patterns, to prioritizing fixes, implementing prototype changes, and communicating redesign outcomes to stakeholders. Use the artifacts below to navigate lessons, activities, and reference materials.

Collecting and Organizing Test Data

Explains how to transform raw observations, recordings, and notes from usability sessions into structured, actionable insights, guiding learners and instructors through systematic data collection and organization methods.

Interpreting Error Analysis
Topic Detail .html

Teaches learners how to move beyond surface-level error observations to diagnose what user mistakes reveal about underlying interface problems, covering classification, interpretation, and the analytical process of error analysis.

Prioritizing Usability Improvements

Addresses how to evaluate and rank usability problems when resources are limited, helping learners apply frameworks for weighing severity, frequency, and impact to decide which issues to fix first in a realistic project context.

Principles of Iterative Redesign

Introduces the iterative redesign process — covering its core principles of hypothesis, change, testing, and evaluation in repeated cycles — and explains why multiple design passes based on real user feedback outperform single-pass design attempts.

Implementing Redesign Changes in Prototypes

Guides learners through translating usability test findings into deliberate, concrete prototype changes, covering how to implement redesign decisions in a way that produces a measurably improved next version of the design.
