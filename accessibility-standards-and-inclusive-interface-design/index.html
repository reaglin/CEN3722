CEN3722 — Introduction to Human Computer Interfaces

Accessibility Standards and Inclusive Interface Design

This module explores the principles and practices behind designing digital experiences that are accessible to all users. Topics include WCAG guidelines and POUR principles, accessible color and visual design, keyboard navigation patterns, and screen reader compatibility — equipping learners with the knowledge to evaluate and build interfaces that meet modern accessibility standards.
