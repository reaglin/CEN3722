CEN3722 — Introduction to Human Computer Interfaces

Controlled User Testing and Data Collection

This module examines the principles and practices of conducting rigorous, controlled usability studies. Topics span experimental design, participant recruitment, task scenario authoring, structured data collection techniques, and the interpretation of usability metrics — equipping you with the skills to plan, run, and analyse user tests with confidence.
