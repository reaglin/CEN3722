Controlled User Testing and Data Collection

This module explores the theory and practice of conducting controlled usability studies. You will learn how to design rigorous test protocols, recruit and brief participants, craft representative task scenarios, and apply appropriate data collection techniques to gather meaningful usability metrics — skills essential to evidence-based interface design.
