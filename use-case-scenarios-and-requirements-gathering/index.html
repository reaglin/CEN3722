CEN3722 — Introduction to Human Computer Interfaces

Use Case Scenarios and Requirements Gathering

This module explores the foundational methods for capturing user needs and translating them into structured requirements. Topics include use case modelling, stakeholder identification, requirements gathering techniques, and task analysis — providing the practical skills needed to bridge user research and system design.
