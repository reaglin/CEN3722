CEN3722 — Introduction to Human Computer Interfaces

Accessibility Standards and Inclusive Interface Design

This module explores the principles and practices behind building digital experiences that work for everyone. Learners will examine WCAG guidelines, the POUR framework, accessible visual design, keyboard navigation patterns, and screen reader compatibility to develop inclusive, standards-compliant interfaces.
