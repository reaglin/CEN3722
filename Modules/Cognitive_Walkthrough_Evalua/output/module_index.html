CEN3722 — Introduction to Human Computer Interfaces

Cognitive Walkthrough Evaluation Method

This module introduces the Cognitive Walkthrough as a structured usability inspection technique. Learners will explore its theoretical foundations, learn how to prepare and execute a walkthrough, identify and document failure points, and practice communicating usability findings to design stakeholders.
