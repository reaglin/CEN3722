Controlled User Testing and Data Collection

This module explores the end-to-end process of planning and running controlled usability studies. Topics range from experimental design fundamentals and participant recruitment to task scenario writing, data collection methods, and structuring results for analysis. This reading describes the think-aloud protocol method, explaining how to instruct participants to verbalize their thoughts during tasks, the difference between concurrent and retrospective approaches, and how facilitators use it to capture real-time user reasoning.

Quantitative Data Collection

This reading covers quantitative data collection in usability testing, explaining what numerical metrics such as task completion rates, time-on-task, and error counts measure, how to record them consistently, and how they are used to compare and benchmark interface performance.

Qualitative Data Collection

This reading explains qualitative data collection methods in usability testing, covering observational note-taking, verbal data capture, and how these techniques reveal the reasons behind user behavior to complement numerical metrics.
