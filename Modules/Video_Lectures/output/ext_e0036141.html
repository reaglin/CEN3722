Author / Site: Daytona State College - Instructional Resources

Summary: This video lecture covers Task Analysis as part of a Human-Computer Interaction or interface design course (CEN3722) at Daytona State College. It addresses standard methods and frameworks used to analyze user tasks in the context of interactive system design. The content is intended to support students in understanding how to systematically break down user goals and actions.

Relevance to Module: Task Analysis is a foundational technique in interaction design, directly informing how interfaces are structured to support user workflows. This video aligns with the module's coverage of Task Analysis and connects to broader topics such as understanding users, interaction design, and usability evaluation covered throughout the module.

Pedagogical Purpose

This video lecture provides an alternate or supplementary explanation of Task Analysis methods, giving students a structured walkthrough that directly supports MO3 [Apply] — the ability to apply Hierarchical Task Analysis to decompose a user goal into structured subtasks that inform interface design decisions. By presenting a worked conceptual framework, it helps students understand the process before applying it independently. It may also reinforce MO4 [Evaluate] by contextualizing how task decomposition informs the selection and conduct of usability evaluation methods.
