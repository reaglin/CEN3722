Module 4: Task Analysis for Interface Design

This module introduces systematic task analysis methods used to understand how users accomplish goals within an interface. Topics include task analysis fundamentals, Hierarchical Task Analysis (HTA), Cognitive Task Analysis (CTA), and guidelines for selecting the appropriate method. The artifacts below provide structured content, learning outcomes, and a hands-on group project to support your progress through this module.
