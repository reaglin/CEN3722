CEN3722 — Introduction to Human Computer Interfaces

Module 4 — Task Analysis for Interface Design

This module explores the theory and practice of task analysis as a foundational method in user-centred interface design. Topics include Hierarchical Task Analysis (HTA), Cognitive Task Analysis (CTA), data-collection strategies, documentation techniques, and the application of these methods within a collaborative group project.
