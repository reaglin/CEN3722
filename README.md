# CEN3722 - Introduction to Human Computer Interfaces

This course covers the basic elements of design and evaluation of computer interface. Standard design interface evaluation methods are covered. The course requires a design project which involves development of a prototype to fulfill a set of requirements and a full evaluation of the usability of the developed prototype.

## Modules

1. 1 - HCI Foundations and Course Project Setup
2. 2 - Project Scoping and App Platform Selection
3. 3 - Use Case Scenarios and Requirements Gathering
4. 4 - Task Analysis for Interface Design
5. 5 - AI-Assisted Design and Development Workflows
6. Interface Prototyping with Figma
7. Cognitive Walkthrough Evaluation Method
8. Heuristic Evaluation and Nielsen's 10 Principles
9. Functional Prototype Development and Testing Preparation
10. Controlled User Testing and Data Collection
11. Analyzing User Testing Results and Iterative Redesign
12. Accessibility Standards and Inclusive Interface Design
13. App Publication Strategies and Store Requirements
14. HCI Design Documentation and Development Reporting
15. Final HCI Evaluation, Reflection, and Lessons Learned
16. Video Lectures
