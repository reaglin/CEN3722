CEN3722 - Introduction to Human Computer Interfaces

This course covers the basic elements of design and evaluation of computer interface. Standard design interface evaluation methods are covered. The course requires a design project which involves development of a prototype to fulfill a set of requirements and a full evaluation of the usability of the developed prototype.

Modules

  • Module 1

    HCI Foundations and Course Project Setup

    Introduces core Human-Computer Interaction concepts and establishes team-based project infrastructure including GitHub, Figma, AI tools, and development environments. Students leave ready to begin collaborative design and development in week two.

    17 items
  • Module 2

    Project Scoping and App Platform Selection

    Covers how to define the scope of an HCI design project and how to evaluate the four target platforms — Android, iOS, Windows, and Web — to select the most appropriate one. Students produce a formal project description outlining goals, constraints, and chosen tools.

    21 items
  • Module 3

    Use Case Scenarios and Requirements Gathering

    Teaches students how to identify users, goals, and interaction contexts by writing comprehensive Use Case Scenarios for a software project. Students learn to systematically enumerate all realistic usage paths and edge cases the interface must support.

    20 items
  • Module 4

    Task Analysis for Interface Design

    Introduces hierarchical and cognitive task analysis methods used to decompose user goals into discrete, observable steps that inform interface structure. Students apply these methods to produce full task analysis documentation for their group project.

    18 items
  • Module 5

    AI-Assisted Design and Development Workflows

    Explores how AI coding assistants such as Claude Code, GitHub Copilot, and Codex integrate into modern HCI design and development pipelines. Students learn practical workflows for using AI to accelerate prototyping while maintaining design quality.

    16 items
  • Module 6

    Interface Prototyping with Figma

    Covers Figma's core features — frames, components, auto-layout, and interactive prototyping — as tools for creating high-fidelity interface mockups. Students build a complete, shareable Figma prototype of their group project ready for peer evaluation.

    17 items
  • Module 7

    Cognitive Walkthrough Evaluation Method

    Explains the theory and step-by-step procedure of the Cognitive Walkthrough usability inspection method, including how to identify task sequences, evaluate learnability, and document failure points. Students independently apply the method to three real peer prototypes.

    19 items
  • Module 8

    Heuristic Evaluation and Nielsen's 10 Principles

    Presents Nielsen's ten usability heuristics and the structured process for conducting a Heuristic Evaluation, including severity rating and aggregating findings across evaluators. Students independently evaluate three peer prototypes and produce formal HE reports.

    19 items
  • Module 9

    Functional Prototype Development and Testing Preparation

    Guides students from high-fidelity mockups to coded, deployable prototypes suitable for controlled usability testing, covering transition strategies and development environment use. Students also design user proficiency surveys and testing protocols for the upcoming user studies.

    14 items
  • Module 10

    Controlled User Testing and Data Collection

    Covers experimental design for usability testing, including participant selection, task scenario scripting, think-aloud protocols, and quantitative and qualitative data capture. Student teams conduct live user testing sessions and compile structured results for analysis.

    18 items
  • Module 11

    Analyzing User Testing Results and Iterative Redesign

    Teaches methods for interpreting usability test data — including error analysis, task completion rates, and satisfaction scores — to prioritize and implement interface improvements. Students apply findings from their user testing to refine and update their prototypes.

    16 items
  • Module 12

    Accessibility Standards and Inclusive Interface Design

    Introduces WCAG guidelines, accessible color contrast, keyboard navigation, screen reader compatibility, and other inclusive design principles essential for modern interfaces. Students audit their own prototypes for accessibility gaps and apply corrective design patterns.

    15 items
  • Module 13

    App Publication Strategies and Store Requirements

    Covers the submission processes, asset requirements, review guidelines, and compliance considerations for the Google Play Store, Apple App Store, Microsoft Store, and web deployment. Students finalize their application builds and prepare publication-ready deliverables.

    14 items
  • Module 14

    HCI Design Documentation and Development Reporting

    Explains how to write a professional HCI development report that traces design decisions from requirements through evaluation to final implementation, linking evidence to outcomes. Students produce a comprehensive group development report documenting their full design process.

    16 items
  • Module 15

    Final HCI Evaluation, Reflection, and Lessons Learned

    Synthesizes all course concepts by reviewing how analysis, prototyping, and evaluation methods contributed to the quality of each team's final product, with emphasis on connecting HCI theory to real design outcomes. Teams receive structured feedback on design quality, process execution, and collaboration.

    16 items
  • Module 16

    Video Lectures

    This module contains added video lectures covering Cognition and Perception, Attention and Memory, Knowledge and Mental Models, Interface Metaphors and Conceptual Models, Human Errors, Learning, Understanding Users (2 videos), Task Anlaysis, Interaction design, Mobile Interaction design, Prototyping, Usability Evaluation, User testing, Human Factors, Ergonomics, Automation, Displays, Computer Supported Cooperative Work, Advanced Interfaces.

    30 items
